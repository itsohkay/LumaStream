LUMASTREAM — THE STORYVERSE

Files included:
- index.html: website layout and page sections
- style.css: responsive visual design and layout styling
- script.js: catalogue rendering, search, filters, modal, My List and form validation
- catalogue.json: catalogue data
- README.txt: setup instructions

RUN THE PROJECT
1. Extract the ZIP folder.
2. Open the folder in Visual Studio Code.
3. Use Live Server or another local web server to run index.html.
4. Keep all files in the same folder so the HTML, CSS, JavaScript and JSON references work.
5. Internet connection is required for Bootstrap, fonts and remote image/trailer links.

FEATURES
Catalogue search and filters, dynamic JSON data loading with fallback data, title details modal, trailer links, My List saved in localStorage, demo sign-in form validation and responsive layouts.

This is an educational website prototype. It does not host movies or create real user accounts.

The visual design uses an original comic-cinematic style inspired by modern action-game promotional sites; it is not a copy of Marvel Rivals' source CSS.
