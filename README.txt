LUMASTREAM - MEDIA CORRECTED BUILD

Open index.html through Live Server or deploy the folder to GitHub Pages.

Movie artwork is requested from Wikipedia at runtime. The site looks for a poster/cover image file on the article first, then uses the article thumbnail. If an image is not available, it falls back to a YouTube thumbnail when a trailer ID exists, otherwise the card's built-in artwork fallback is shown. Artwork requires an internet connection.

Trailer embeds use only the six trailer links that were already included in the original project. Other catalogue titles have a YouTube search fallback instead of an unverified video ID. YouTube may restrict embedding for some videos; use the Open YouTube button in that case.

The CSS design has been preserved. The added CSS only supports the embedded trailer player.
